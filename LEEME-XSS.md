# Atlas — protección HTML de tickets (desarrollo)
Base: atlas-n8n-cid-seguridad-base.zip con atlas-n8n-cid-seguridad-local.zip aplicado. Contiene ambos controladores completos, la vista de tickets, un nuevo servicio y un test. No incluye .env, credenciales, SQL ni archivos históricos.
Requiere PHP ext-dom (ya requerida por dompdf/phpspreadsheet). En escritura conserva CID, imágenes data raster y enlaces HTTP(S); al mostrar tickets permite únicamente imágenes raster registradas para el mensaje. Bloquea imágenes remotas, estilos, atributos activos y elementos no permitidos. Por tanto firmas externas y algunos estilos históricos pueden no mostrarse. No cambia la BD ni los archivos existentes. No representa una auditoría XSS de todos los módulos (incluido correo independiente y CCI).
Aplicar únicamente en /c/xampp/atlas-n8n-http-test, con copia previa de los 3 archivos existentes. Ejecutar php tests/TicketHtmlSanitizerTest.php y abrir TCK-5. No desplegar antes de completar el workflow.
Validación realizada: sintaxis de archivos modificados, 10 pruebas CID, 6 pruebas alcance n8n. El PHP del entorno de generación no dispone de DOM: el test completo debe ejecutarse en XAMPP; el fallback de visualización se verificó.
